== Description ==

**ALOOKHOR Control Center** پنل مدیریت لوکس بوتیک آلو بخارا است که بخش‌های اصلی سایت را در یک داشبورد Dark Glass + Gold مدیریت می‌کند.

* **هدر حرفه‌ای با شورت‌کد:** [alookhor_portal_header]
* **دسته‌بندی مدیریت‌شده:** [alookhor_managed_categories]
* **Hero مدیریت‌شده:** [alookhor_managed_hero]
* **ویژگی‌های سایت:** [alookhor_managed_features]
* **سبد خرید اختصاصی آلوخور:** Renderer واحد با نشست بومی WooCommerce، تغییر تعداد، حذف، کد تخفیف و پیشنهاد محصول
* **Responsive:** 320 تا 1920px بدون overflow
* **آپدیت آنی:** از مسیر Update خود WordPress/Control Center
* **حافظه پایدار:** تنظیمات در wp_options نگهداری می‌شوند

== Installation ==
این افزونه از مسیر Update خود WordPress/Control Center به‌روزرسانی می‌شود و نیازی به نصب دستی ZIP ندارد.
